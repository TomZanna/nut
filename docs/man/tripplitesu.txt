TRIPPLITESU(8)
==============

NAME
----

tripplitesu - Driver for Tripp-Lite SmartOnline (SU) UPS equipment

SYNOPSIS
--------

*tripplitesu* -h

*tripplitesu* -a 'UPS_NAME' ['OPTIONS']

NOTE: This man page only documents the hardware-specific features of the
tripplitesu driver.  For information about the core driver, see
linkman:nutupsdrv[8].

SUPPORTED HARDWARE
------------------

This driver supports the Tripp Lite SmartOnline family (via the serial port).

EXTRA ARGUMENTS
---------------

This driver supports the following optional settings in the
linkman:ups.conf[5]:

*lowbatt*='num'::
Set the low battery warning threshold in percent at which shutdown is
initiated by linkman:upsmon[8].  By default, the UPS may not report low battery
until there are only a few seconds left.  Common values are around 25--30.

*command_delay*='microseconds'::
Set a delay in microseconds to be applied before each command sent to the UPS.
The default value is -1 (disabled). If experiencing intermittent communication
timeouts when multiple commands are sent in rapid succession, set this to
1000000 (1 second) or adjust as needed. Set to 0 for no delay (explicitly enabled
but with zero duration).
+
This delay helps prevent "read timeout" errors when the hardware buffer is
not ready to accept new commands immediately after completing the previous one.
+
*Note:* If a communication timeout is detected and command_delay is -1 (default
disabled state), the driver will automatically enable it with a 1-second delay
and log a warning message. Auto-enable will not activate if command_delay is
explicitly set to 0 or any other value.

*shutdown_delay*='seconds'::
Set the delay before shutdown in seconds (default: 10). This value is used when
executing shutdown commands such as `shutdown.reboot`, `shutdown.return`, and
during the driver's shutdown sequence. Minimum value is 1 second.
+
*Note:* For `shutdown.reboot.graceful`, the driver will use at least 60 seconds
for the shutdown delay, even if shutdown_delay is configured to a lower value.
If shutdown_delay is set higher than 60 seconds, that value will be used instead.

*reboot_delay*='minutes'::
Set the delay before reboot in minutes (default: 1). This value is used when
executing reboot commands such as `shutdown.reboot` and `shutdown.return`.
Minimum value is 1 minute.

INSTANT COMMANDS
----------------

This driver supports several instant commands (see linkman:upscmd[8]):

*shutdown.reboot*::
Shut down the load immediately, then restart it.
+
*Note:* This command can power on a UPS that is currently off, not just
reboot a running UPS.
+
Optional parameter: Specify custom delays as "shutdown_delay" (seconds) or 
"shutdown_delay.reboot_delay" (shutdown in seconds, reboot in minutes). 
Example: `upscmd ups shutdown.reboot 5.2` shuts down in 5 seconds and 
reboots after 2 minutes.

*shutdown.reboot.graceful*::
Shut down the load after a delay (minimum 60 seconds), then restart it.
+
*Note:* This command can power on a UPS that is currently off, not just
reboot a running UPS.
+
Optional parameter: Specify custom delays as "shutdown_delay" (seconds) or 
"shutdown_delay.reboot_delay" (shutdown in seconds, reboot in minutes). 
The shutdown delay will be at least 60 seconds for graceful operation.
Example: `upscmd ups shutdown.reboot.graceful 90.3` shuts down in 90 seconds 
and reboots after 3 minutes.

*shutdown.return*::
Shut down the load immediately, then restart it when power returns.
+
Optional parameter: Specify custom delays as "shutdown_delay" (seconds) or 
"shutdown_delay.reboot_delay" (shutdown in seconds, reboot in minutes).
Example: `upscmd ups shutdown.return 15.1` shuts down in 15 seconds and 
reboots after 1 minute when power returns.

*shutdown.stop*::
Stop a pending shutdown.

*test.battery.start*::
Start a battery test.

*test.battery.stop*::
Stop a battery test.
